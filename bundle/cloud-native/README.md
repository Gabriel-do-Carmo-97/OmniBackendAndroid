# ☁️ Módulo `:bundle:cloud-native` — Nuvens Públicas Globais de Escala Massiva

O módulo **`:bundle:cloud-native`** agrupa as maiores plataformas de **nuvem pública e alcance global** (`firebase`, `supabase`, `amplify`, `cloudflare`).

---

## 🛠️ O que está incluído?

- `:core`
- `:backend:firebase`
- `:backend:supabase`
- `:backend:amplify`
- `:backend:cloudflare`

---

## 📥 Como Importar

```kotlin
dependencies {
    implementation(project(":bundle:cloud-native"))
}
```

---

## 🎯 Quando Usar?

- **Startups B2C & Apps de Grande Escala:** Aplicações com milhões de usuários ativos simultâneos.
- **Auto-Scaling Elástico Automático:** Gerenciamento totalmente automatizado de carga e servidores sem preocupações com infraestrutura física.
