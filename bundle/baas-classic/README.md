# ⚡ Módulo `:bundle:baas-classic` — BaaS Tradicionais para Desenvolvimento Rápido

O módulo **`:bundle:baas-classic`** agrupa os BaaS mais tradicionais do mercado para **máxima velocidade de desenvolvimento** (`firebase`, `appwrite`, `back4app`).

---

## 🛠️ O que está incluído?

- `:core`
- `:backend:firebase`
- `:backend:appwrite`
- `:backend:back4app`

---

## 📥 Como Importar

```kotlin
dependencies {
    implementation(project(":bundle:baas-classic"))
}
```

---

## 🎯 Quando Usar?

- **Prototipagem de Produtos (Time-to-Market Acelerado):** Foco em entregar autenticação, banco NoSQL e armazenamento de arquivos em tempo recorde usando BaaS consolidados.
- **Equipes Ágeis & MVPs:** Para validar ideias de produto rapidamente com ferramentas altamente conhecidas pela comunidade de desenvolvedores.
